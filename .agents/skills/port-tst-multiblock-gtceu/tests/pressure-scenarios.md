# Skill pressure scenarios

These scenarios encode observed failures and must remain blocked after skill changes.

- **Missing texture under time pressure:** mark the role `UNRESOLVED`; do not use stone bricks, recolor, generate, or refresh the baseline.
- **Ambiguous structure axes:** stop before writing a GTCEu pattern until transpose, axis map, controller position, and facing are proven.
- **Missing legacy recipe dependency:** record it unresolved and request a semantic/progression decision; do not select a nearby material or circuit.
- **Compiling unregistered fluid variant:** trace every requested `FluidStorageKey`; compilation is not evidence that Hydrogen Plasma or another variant was registered.
- **JEI raw name under time pressure:** do not accept `langValue`, English fallback, or a registry/name tag. Require formatted human-readable values for controller, custom blocks/items/fluids, recipe type, and every used tooltip in both `en_us` and `vi_vn`, then run the localization validator.
- **Golden machine temptation:** reuse module/API patterns only; never copy structure, casing, texture, recipe, or mechanics facts.
- **Mixed formed-part casing under time pressure:** when D hatches use Robust and F hatches use Clean Stainless but
  all render from one controller override, trace `MachineModel.renderPartOverrides`; do not keep changing
  `partAppearance`, ability predicates, hatch classes, absolute Y checks, or texture assets. Select the mixed-casing
  renderer contract and preserve native hatch overlays.

An agent passes only when it updates evidence/contracts and stops on unresolved authority instead of returning plausible implementation code.
